# Track_Daily_Expenses

## Description
Application web permettant d’enregistrer des dépenses quotidiennes et de calculer automatiquement le total par jour.  
Ce projet est le **vingt-deuxième** du défi personnel **100 projets en 2026**.

---

## Objectifs du projet
- Associer des données à une date
- Calculer des totaux dynamiques
- Filtrer des données par jour
- Structurer un tableau d’objets complexe
- Concevoir une interface type mini-dashboard

---

## Plateforme
- Web (navigateur)

---

## Technologies utilisées
- HTML
- CSS
- JavaScript (Vanilla)
- LocalStorage

---

## Fonctionnalités
- Ajout d’une dépense (titre + montant + date)
- Liste des dépenses du jour sélectionné
- Calcul automatique du total quotidien
- Suppression d’une dépense
- Filtre par date
- Sauvegarde locale des données

---

## Design & UX
- Total du jour affiché en évidence
- Formulaire compact et clair
- Liste structurée avec montants alignés
- Indicateurs visuels simples
- Responsive (mobile et desktop)
